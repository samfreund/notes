\section*{Notable Feature Processing}
\begin{itemize}
\item Data types were explicitly assigned: categorical (Species/Month/Site/Location), integer (Year/Age/Number/binary traits), and float (continuous trait variables).
\item Missing values were present in Diameter (6), Taper (17), TI (17), Mass (1), d13C (2), d15N (2), and CN (2).
\item For inferential analysis, complete-case rows for tested traits were used (listwise deletion on required columns).
\item Outliers were retained because extreme values may reflect real dietary/ecological variability and robust nonparametric tests (Kruskal-Wallis, Mann-Whitney) were used.
\end{itemize}

\section*{Notes}
\begin{itemize}
\item Species classes are imbalanced (Bobcat n=57, Coyote n=28, GrayFox n=25), so medians and robust tests are emphasized over means alone.
\item Contextual variables (site/month/location/year) are useful for collection metadata but were excluded from the species-discrimination hypothesis tests.
\item The dataset supports strong comparisons for several traits (mass, diameter, d13C, d15N, C:N, segmented), but results are site- and time-specific to central coastal California.
\end{itemize}
