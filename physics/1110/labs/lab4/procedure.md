# Projectile Motion Lab Measurement Steps

## Phase 1: Determine Initial Speed (Horizontal Launch)

### Setup
1. Position the spring gun horizontally at the edge of the table
2. Place the catch box on the floor at an appropriate distance
3. Measure and record the height from the launch point to the floor (y₀)
4. Set the initial horizontal position as your reference point (x₀ = 0)

### Data Collection
5. Launch the projectile horizontally multiple times (at least 5-10 trials)
6. Measure the horizontal distance traveled (range) for each trial
7. Record all range measurements
8. Calculate the average range (x̄) and uncertainty (uₓ)

### Calculate Initial Speed
9. Use equation y = y₀ - ½gt² to find the flight time:
   - When projectile hits floor: y = 0
   - Solve for t: t = √(2y₀/g)
10. Use equation x = x₀ + v₀t to find initial speed:
    - v₀ = x̄/t (using average range and calculated time)
11. Calculate uncertainty in initial speed (uᵥ₀)

## Phase 2: Angled Launch Prediction

### Setup for Angled Launch
12. Prop up the gun platform at a stable angle θ
13. Measure the angle θ using trigonometry and appropriate measurements
14. Measure the new initial height (y₀) above the table surface
15. Set coordinate system with launch point as reference

### Calculate Initial Velocity Components
16. Calculate horizontal component: vₓ₀ = v₀ cos(θ)
17. Calculate vertical component: vᵧ₀ = v₀ sin(θ)

### Make Prediction
18. Use equations of motion to predict height at x = 1.5 m (150 cm):
    - From x = x₀ + vₓ₀t, solve for time: t = x/vₓ₀
    - Substitute into y = y₀ + vᵧ₀t - ½gt² to find height
19. Convert all units to be consistent (meters or centimeters throughout)
20. Double-check calculations before reporting prediction

## Phase 3: Test Prediction
21. Report predicted height to instructor
22. Aim the projectile in correct azimuth (horizontal direction)
23. Fire projectile and observe if it passes through the ring at predicted height

## Key Measurements Needed
- **Horizontal launch height** (table to floor)
- **Multiple range measurements** for consistency
- **Launch angle θ** for angled shot
- **Initial height above table** for angled shot
- **Target horizontal distance** (typically 150 cm)

## Important Notes
- Keep units consistent throughout (preferably use meters)
- Take multiple measurements for better accuracy
- Account for measurement uncertainties
- Ensure stable, repeatable launch conditions
